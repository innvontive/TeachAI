# TeachAI: learn to use AI assistants with a free 8-lesson tutor

Turn Claude, ChatGPT, Gemini, Grok or any other AI assistant into a patient teacher that shows you how to use it, in 8 short hands-on lessons, in your own language.

**Languages:** [English](prompts/en.txt) · [हिन्दी](prompts/hi.txt) · [मराठी](prompts/mr.txt) · [தமிழ்](prompts/ta.txt) · [ગુજરાતી](prompts/gu.txt)

Step-by-step page with copy buttons: **https://innvontive.com/learn-ai/**

## The lessons

1. What an AI assistant is, and what it is not
2. Your first conversation
3. Asking well: Goal, Background, Format
4. Going back and forth to improve an answer
5. Photos, files and voice
6. Checking the answers
7. Privacy and safety
8. Everyday uses, and choosing an assistant

Each lesson is short, uses examples from your own work or life, and ends with something to try. The tutor waits for you before moving on. Say "next", "repeat", "simpler", "skip" or "go back" at any time.

## How to use it

### Any assistant (free, works everywhere)

1. Open the text for your language above.
2. Copy all of it.
3. Start a **new chat** in Claude, ChatGPT, Gemini, Grok, Copilot, Meta AI or DeepSeek and paste it as your first message.
4. Answer the tutor's three questions. That's it.

If your assistant can open web links, you can instead send: *"Read https://innvontive.com/learn-ai/en.txt and follow it."* (use `hi.txt`, `mr.txt`, `ta.txt` or `gu.txt` for the other languages).

### Claude: install it as a skill (lasts for every chat)

1. Download [`ai-assistant-tutor.zip`](ai-assistant-tutor.zip).
2. In Claude, open **Settings → Capabilities → Skills**, choose **Upload skill** and pick the zip file.
3. Turn the skill on.
4. In any chat, say *"Teach me how to use Claude"* (or ChatGPT, Gemini, Grok).

### ChatGPT, Gemini and Grok: save it so you don't paste it every time

These apps let you save instructions and reuse them, but their menus change often:

- **ChatGPT:** create a skill (or a Project) and paste the text as its instructions.
- **Gemini:** create a skill (Gemini is replacing "Gems" with skills from November 2026), paste the text as its instructions, then start it by typing `/` in a chat.
- **Grok:** paste the text at the start of a chat, or into custom instructions if your version has them.

## Is it safe?

The tutor is plain text. There are no scripts and nothing to run. Read the [skill](skill/ai-assistant-tutor/SKILL.md) or the [prompt](prompts/en.txt) before using it. The tutor itself teaches you never to share passwords, OTPs, Aadhaar, PAN, or bank or card numbers with an AI assistant.
